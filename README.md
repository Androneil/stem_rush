# STEM Rush

An interactive STEM discovery platform built for curious Jamaican students.

STEM Rush helps students move from “I wonder…” to “I made this.” The first release includes:

- a three-question STEM Compass that recommends a discovery lane;
- four practical lanes across engineering, technology, science, and the environment;
- three low-cost starter missions students can begin immediately;
- a simple roadmap from first experiment to sharing a finished project; and
- a responsive, accessible experience for desktop and mobile.

## Run locally

```bash
npm ci
npm run dev
```

## Validate a production build

```bash
npm run build
```

## Technology

- Next.js-compatible routing with Vinext
- React and TypeScript
- Tailwind CSS
- Cloudflare Workers deployment output

## Project status

This is the first working product slice. Future releases can expand the mission library, add student progress, and connect learners with verified Jamaican STEM opportunities.
